# Source-locator pattern design

## When selected

“Where does it say”, “citation”, “what section”, short citation-like queries, …

## Answer shape (legal)

For each hit (in order):

- Primary citation, family, heading, subsection path, pages  
- **Relevance** one-liner (first sentence of snippet)  
- **Full excerpt** (unchanged grounding)  
- Normalized blocks as today  

## Answer shape (policy)

- Section title, anchor, relevance lead-in, full excerpt, normalized blocks  

Maximizes **locatability** while keeping raw text present.
