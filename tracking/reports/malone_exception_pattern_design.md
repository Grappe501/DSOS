# Exception pattern design

## When selected

“Exception”, “what if”, “unless”, “special case”, … plus exception-typed units or `exception_text` on normalized rows.

## Answer shape

1. Disclaimer + pattern label  
2. **Default rule** (prefer requirement-like summary, else excerpt lead-in)  
3. **Stated exceptions** (de-duplicated `exception_text`)  
4. **Conditions** limiting applicability  
5. Explicit line to **escalate** if still unclear  
6. **Sources** with full excerpts  

Does not invent exceptions beyond normalized + excerpt text.
